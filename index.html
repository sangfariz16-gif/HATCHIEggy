I · Terms

The Terms of the Pact

  1. 4,444 eggs. When the last is sworn, the book is closed. Supply never increases.
  2. AI agents only. This site never asks you to connect a wallet. Your agent signs for you. There is no .ai Agent ID gate — any agent that can send a BNB Chain transaction can mint.
  3. Your wallet’s first mint is free. Send exactly 0 BNB; you pay only gas.
  4. Every mint after that costs 0.001 BNB. Up to 10 per wallet. Overpaying reverts.
  5. Every paid mint earns 120,000 HATCH. Claimable on-chain whenever you like with claim() on the HATCH token contract.
  6. The market opens after sell-out. No trading venue is promised before then.
  7. No promises. Eggs and HATCH are collectibles. No returns, price or profit are implied.

VI · Questions

Questions

Which agents can mint?

Binance Agentic Wallet, or any agent that can send a BNB Chain transaction. There is no .ai Agent ID gate on this contract — any agent can mint, up to 10 per wallet.

Why would my agent’s mint fail?

Almost always the amount. Send exactly 0 for a wallet’s first mint and exactly 0.001 BNB for each after; overpaying also reverts. Ask the agent to read nextPrice(address) first. Also check the wallet has not reached 10.

How do I get my HATCH?

Ask your agent to call claim() on the HATCH token (0xE20a294F8a990743ce7Cf66843bBc407e7828FBA) from the minting wallet, or claimFor(address) from any wallet. claimable(address) shows what is waiting.

Can I mint several at once?

Yes — mint(uint256 quantity). The value is priceFor(address, quantity); for a new wallet the first one in the batch is free.

Where does the art live?

Every egg shares the same golden cracked crystal egg artwork (assets/hero.jpg). Metadata is live at www.hatchieggy.fun/metadata/1 … /4444. Rarity (Common 1–2222, Rare 2223–3333, Epic 3334–3999, Legendary 4000–4332, Mythic 4333–4444) and traits are metadata only.

Is this an investment?

No. Eggs and HATCH are collectibles. Never spend more than you are happy to keep as art.
